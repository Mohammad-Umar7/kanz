# Eval photos

Test images for the Kanz AI classification eval; expected results for each file live in `../manifest.json`.
Image files here are git-ignored (only this README and `CREDITS.md` are committed), so fetch or add them locally.
To add your own: drop phone photos (any `.jpg` / `.png`) into this folder and add an entry for each to `../manifest.json` (`file`, `expected_category`, `expected_hazard`, `expected_items_min`, `notes`).
