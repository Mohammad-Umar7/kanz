# Kanz

Kanz (Arabic كنز, "treasure") is a mobile app that looks at things you are about to throw away and shows you what they can become. Photograph a glass jar, an old t-shirt or a wooden crate: Kanz identifies the materials, suggests upcycling projects with step-by-step tutorials and generated before/after images, explains how to recycle or donate the item, and points you to drop-off points nearby.

Built for the 20th IEEE UAE Student Day, Software Engineering Project competition 2025-26.

Setup, architecture and the user manual are being written; see `PLAN.md` for the current state of the build.
